Zmień status zlecenia naprawy

Łukasz Bera

@startuml start :Wybierz opcje "Moje zlecenia"; repeat :Wyswietl liste przydzielonych zlecen; :Wybierz zlecenie z listy; :Wyswietl szczegoly zlecenia z aktualnym statusem; backward:Poinformuj, ze zmiana statusu nie jest mozliwa; repeat while (Zlecenie ma status "rozliczone"?) is (tak) not (nie) :Wybierz opcje "Zmien status"; repeat repeat :Wyswietl liste statusow dozwolonych dla etapu zlecenia; :Wybierz nowy status i opcjonalnie dodaj komentarz; if (Mechanik anuluje?) then (tak) :Pozostaw status bez zmian; end else (nie) endif :Zatwierdz zmiane statusu; :Sprawdz, czy zmiana statusu jest dozwolona; backward:Wyswietl komunikat o braku wykonanych napraw; repeat while ("zakonczone", ale brak zapisanej naprawy?) is (tak) not (nie) backward:Wyswietl komunikat o oczekujacym kosztorysie; repeat while ("zakonczone", ale kosztorys czeka na decyzje klienta?) is (tak) not (nie) :Zapisz nowy status z data zmiany; :Wyswietl potwierdzenie zmiany statusu; stop @enduml
